# @opentiny/genui-sdk-materials-angular-opentiny-ng

OpenTiny Angular 组件物料与 render-config，供 Angular 版 GenUI 渲染器使用。

## 安装

```bash
pnpm add @opentiny/genui-sdk-materials-angular-opentiny-ng
```

## 导出

| 子路径 | 说明 |
|--------|------|
| `.` | 物料入口 |
| `./render-config` | 白名单与 bundle 配置 |
